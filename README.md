**Fully static** — plain HTML/CSS/JS, no build step, no dependencies, no backend.

## Deploy on Vercel (free)

1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New → Project** and select the `atta-portfolio` repository.
3. Framework Preset: **Other** (it's static — no build needed).
4. Build Command: leave empty. Output Directory: leave as-is (repo root).
5. Click **Deploy**. Done — you get a live `*.vercel.app` URL in under a minute.

Optional: add a custom domain later from the project's **Settings → Domains**.
